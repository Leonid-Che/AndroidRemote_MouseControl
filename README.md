# TouchCursor — управление курсором Windows 10 со смартфона Android по Wi-Fi

Смартфон (Android 10+, портретная ориентация) работает как тачпад + кнопки мыши
для компьютера с Windows 10. Связь — через домашнюю Wi-Fi сеть (TCP/UDP, без облака).

## Состав проекта

```
android/  — приложение для смартфона (Java, Android Studio)
pc/       — сервер для компьютера (Python 3 + pyautogui)
```

## Как это работает

### Экран приложения (снизу — две строки кнопок)

| Строка | Кнопки |
|---|---|
| 1 | **УПРАВЛЕНИЕ** (вкл/выкл), **Wi-Fi**, **Резерв-1** |
| 2 | **ЛКМ**, **ПКМ**, **Резерв-2** |

* **УПРАВЛЕНИЕ** — кнопка активации режима: пока «вкл», телефон не регулирует
  свою громкость кнопками, а отправляет клики мыши; экран не гаснет
  (`FLAG_KEEP_SCREEN_ON`), работает foreground-сервис с уведомлением.
* **Громкость+** → левая кнопка мыши: одиночное нажатие = клик,
  двойное = двойной клик, удержание = зажатая ЛКМ (drag), отпускание = отпустить.
* **Громкость−** → правая кнопка мыши по той же схеме.
* **ЛКМ / ПКМ** — экранные кнопки: нажал — зажата, отпустил — отпущена.
* **Wi-Fi** — поиск компьютера в сети (UDP-broadcast) или ручной ввод адреса,
  подключение/отключение (TCP :8721).
* **Резерв-1 / Резерв-2** — зарезервированы на будущее (например, колесо/средняя кнопка).
* Область над кнопками — тачпад: движение пальца = движение курсора,
  один тап = ЛКМ, двойной тап = двойной клик, вертикальный свайп двумя пальцами = колесо.

### Протокол (TCP, текст, `\n`-разделитель)

| Команда | Действие на ПК |
|---|---|
| `M <dx> <dy>` | смещение курсора на дельту в пикселях |
| `DL` / `UL` | левая кнопка нажата / отпущена |
| `DR` / `UR` | правая кнопка нажата / отпущена |
| `DC` / `DD` | двойной клик левой / правой |
| `W <n>` | колесо мыши (n «щелчков») |
| `PING` / `PONG`, `HELLO` / `OK` | служебные |

UDP :8722 — автопоиск: запрос `TOUCHCURSOR_DISCOVER` → ответ
`TOUCHCURSOR_SERVER|<имя ПК>`.

## Установка и запуск

### 1. Компьютер (Windows 10)

1. Установите Python 3.8+ с python.org (обязательно отметьте **Add Python to PATH**).
2. Скопируйте папку `pc\` на компьютер.
3. Запустите двойным кликом **`run_server.bat`** — он сам установит `pyautogui`
   и попробует открыть порты 8721/TCP и 8722/UDP в брандмауэре
   (если прав администратора нет — разрешите подключение во всплывающем окне
   брандмауэра или выполните вручную от администратора):

   ```bat
   netsh advfirewall firewall add rule name="TouchCursor TCP" dir=in action=allow protocol=TCP localport=8721
   netsh advfirewall firewall add rule name="TouchCursor UDP" dir=in action=allow protocol=UDP localport=8722
   ```

4. В консоли появится `Сервер запущен. TCP :8721 | UDP :8722 | ...` — ждите телефон.

Полезные ключи: `--scale 1.5` (чувствительность), `--failsafe`
(курсор в угол экрана = аварийная остановка), `--port`, `--udp-port`.

### 2. Смартфон (Android 10+)

1. Откройте папку `android/` в Android Studio, соберите APK
   (`Build → Build Bundle(s)/APK(s) → Build APK(s)`) и установите на телефон,
   либо соберите из командной строки: `./gradlew assembleDebug`.
2. Телефон и компьютер должны быть в **одной Wi-Fi сети**.
3. Нажмите **Wi-Fi** → **Найти компьютер** (или введите IP вручную) → подключитесь.
4. Нажмите **УПРАВЛЕНИЕ (ВКЛ)** — можно работать. При первом включении
   приложение попросит разрешение на уведомления (нужно для фонового сервиса).

## Безопасность

* Сервер принимает подключения **только из локальных подсетей**
  (192.168/16, 10/8, 172.16/12, loopback); внешние адреса отклоняются.
* Один активный клиент: новое подключение вытесняет прежнее.
* При обрыве связи сервер автоматически **отпускает все зажатые кнопки мыши**.

## Структура кода

**Android (`com.example.touchcursor`):**
* `MainActivity` — UI, обработка кнопок громкости (`onKeyDown/onKeyUp` → перехват,
  громкость не меняется при активном режиме), экранные ЛКМ/ПКМ;
* `MouseButtonMachine` — автомат «клик / двойной клик / удержание»;
* `ControlService` — foreground-сервис (удержание перехвата и уведомления);
* `NetClient` — TCP-клиент с очередью, UDP-поиск сервера;
* `TouchPadView` — тачпад (движение, тап, двойной тап, прокрутка);
* `WifiDialog`, `Prefs`, `Protocol` — настройка связи, хранение, протокол.

**ПК (`pc/touchcursor_server.py`):**
* `TouchCursorServer` — TCP-приёмник + UDP-discovery;
* `ClientSession` — чтение команд одного клиента;
* `CommandExecutor` — очередь исполнения (дельты движения сливаются, клики не теряются);
* `MouseController` — вызовы pyautogui + гарантированное отпускание кнопок.

## Известные ограничения / идеи для резервных кнопок

* Резерв-1 → средняя кнопка мыши / вставка буфера обмена телефона.
* Резерв-2 → регулировка чувствительности тачпада.
* Шифрование (TLS) не реализовано — используйте доверенную домашнюю сеть.
